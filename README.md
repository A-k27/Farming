# Farming
Players manage a virtual farm through text-based interactions where palyers planting crops, harvesting produce, managing resources, and navigating seasonal challenges. All within a terminal interface.

Learning Objectives

Reinforce foundational C++ concepts: variables, loops, conditionals, functions, classes
Apply object-oriented programming (OOP) principles
Explore file handling, game logic, and user input/output
Practice modular design and code documentation
Collaborate using Git and Agile-style development
